# PEKA!!

告知ランプが「ペカッ」と光る瞬間だけを楽しむ、スマホ向けの無料ブラウザゲームです。
HTML / CSS / JavaScript だけで動き、ビルドやサーバーは不要です。

## 遊び方
- **QUICK PEKA**：中央の大きな PUSH ボタンを1回押すと1ゲームです。
- **SLOT PEKA**：3つのボタンを好きな順番で押すと1ゲームです。抽選は最初のボタンを押したときに1回だけ行われ、ボタンの順番は確率に影響しません。
- 当選すると、演出のあと約8秒間、画面全体が虹色に光る「レインボーフィーバー」になります。フィーバー中でも、開始から1秒たてばタップで飛ばして次のゲームへ進めます。最後まで見た場合はランプが点いたままになり、画面をタップすると次のゲームに進みます。フィーバーの長さは `config.js` の `PEKA.FEVER_MS` で変えられ、設定画面でOFFにもできます。
- PCでは Space / Enter で PUSH、← ↓ → または 1 2 3 で SLOT の各ボタンを押せます。
- 画面上部には、設定・確率・前回当選G・総ゲーム数・当選回数・現在のハマりG数が表示されます。

## サウンド
- BGMはオリジナルの8小節ループ（Cメジャー／138BPM）で、Web Audio API でその場で合成しています。最初にどこかをタップすると流れ始めます（ブラウザの自動再生制限のため）。
- 効果音とBGMの音量は、設定画面で別々に調整できます。BGMだけをOFFにしたり、全体をミュートしたりもできます。
- プチュン（暗転フリーズ）の間はBGMが完全に止まり、復帰と同時に再開します。演出中はBGMの音量が下がり、効果音が目立つようになっています。

## 演出（全160種）
- No.01〜60：王道・心理戦・衝撃・フリーズ（プチュン）・カラフル・プレミアの6系統、各10種。
- No.61〜160：**ブラックアウト系 100種**。「暗転の入り方10 × 闇の中の出来事10 × 復活の仕方10 × 発光色10」から、すべて異なる流れになるよう組み合わせて作っています（例：「黄金の眼光」は、ブラウン管が消えるように暗転し、闇の奥で金色の目が光り、白い閃光で復活します）。プチュン系の扱いなので、プチュンモードで出やすくなります。部品と出現率は `config.js` の `PEKA.BLACKOUT` で変えられます。

## GitHub Pages で公開する
1. このフォルダの中身をリポジトリのルートに置き、push します。
2. Settings → Pages で `main` ブランチの `/ (root)` を選びます。

`index.html` をブラウザで直接開いても遊べます。

## ファイル構成
```
index.html
css/style.css
js/config.js          ★ 設定確率・演出モード・演出60種の定義（調整はここだけ）
js/save.js            localStorage
js/core/sound.js      Web Audio API で効果音を合成
js/core/particles.js  Canvas のパーティクル・衝撃波・描画レイヤー
js/core/stage.js      演出API（ランプ・オーラ・フラッシュ・暗転・揺れ・光／揺れ軽減）
js/effects/*.js       演出スクリプト（系統ごとに6ファイル）
js/game.js            抽選とゲーム進行
js/ui.js / main.js    図鑑・統計・設定・入力
```

## バランス調整（`js/config.js`）
| 項目 | 内容 |
|---|---|
| `PEKA.ODDS` | 設定1〜6の当選確率の分母 |
| `PEKA.FX_MODES.*.puchunShare` | 当選時にプチュン系が選ばれる割合 |
| 各演出の `weight` | 同じグループ内での出やすさ |
| 各演出の `timing` | SLOT PEKA で告知が始まるボタン（1〜3） |
| 各演出の `press` / `tease` | ボタンの無反応・音変化／SLOT途中の前振り |

## 演出を追加する
1. `config.js` の `PEKA.EFFECT_TABLE` に1行追加します。
2. `js/effects/` のどれかに `PEKA.FX.<id> = async (S, ctx) => { ... }` を書きます。
   終わったときにランプが点灯していれば、中身は自由に作れます。いちばん簡単なのは `await S.peka({...})` です。

## デバッグ
URL に `?debug` を付けると、図鑑から全演出を見たり再生したりできます。このときの再生は記録されません。

---
グラフィックと効果音はすべてプログラムで生成したオリジナルです。実在する機種のロゴ・画像・音源は使っていません。

# NOMI! CHANCE（`nomi/`）

PEKA!! をベースにした、飲み会向けのパーティーゲームです。`nomi/index.html` を開くと遊べます。GitHub Pages では `/nomi/` で公開されます。

- 2〜20人で順番にPUSHし、当たった人が飲みます。確率は EASY 1/5、NORMAL 1/10、HARD 1/20 から選べます。
- CHANCE MODE（ランプ＋PUSH）と SLOT MODE（3リール＋STOP）があり、統計は両モードで共通です。
- 当選すると、必ずプチュン（ブラックアウト）演出が流れます。演出は4種類で、続いて8秒のレインボーになります。
- TOTAL PUSH／TOTAL HIT／ハマり／前回当選者、プレイヤー別の成績ランキング、当選履歴を localStorage に保存するので、ブラウザを閉じても続きから遊べます。
- PEKA!! の効果音エンジン・描画エンジン・演出API・演出部品は、`nomi/js/engine/` にコピーして同梱しています。そのため **`nomi` フォルダだけを持ち出しても動きます**。PEKA!! 側のエンジンを直したときは、必要に応じてこちらにもコピーしてください。
- 起動に失敗したときは、画面下に原因（読み込めないファイル名など）が表示されます。
- プチュン演出の追加、音声ファイルの割り当て、確率の変更は `nomi/js/config.js` でできます。音声は `nomi/audio/README.md` を見てください。
