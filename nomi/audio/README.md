# プチュン演出の音声ファイル

当選時のプチュン（ブラックアウト）演出ごとに、**別々の音声ファイル**を割り当てられます。

| 演出 | 置くファイル |
|---|---|
| BLUE CROSS | `bluecross.mp3` |
| CRIMSON GLITCH | `crimson.mp3` |
| 斬 -ZAN- | `zan.mp3` |
| VIOLET FLARE | `violet.mp3` |

- このフォルダ（`nomi/audio/`）に上の名前でファイルを置くと、演出が始まると同時にそのファイルが流れます。流れている間は、合成の効果音とBGMが止まります。
- ファイルを置かなければ、ゲームに組み込まれた合成音（Web Audio API）で鳴ります。
- ファイル名や形式（.m4a / .wav など）を変えたいときは、`js/config.js` の `NOMI.PUCHUN` にある `audio` の値を書き換えてください。
- **音源を自動でダウンロードする機能はありません。** 実在機種の音源は著作物です。置くのは、自分で作った音や、利用が許可されている音声だけにしてください。
- GitHub Pages などで公開する場合は、公開してよい音声かどうかも確認してください。
- 演出のタイミングは、暗転の瞬間を0秒として作っています。音声ファイルも、暗転の瞬間に音が鳴り始めるように頭の無音を詰めておくと、映像とよく合います。
